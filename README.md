# 🚀 AutoCount - Platform Otomatisasi Akuntansi Modern

**AutoCount** adalah platform *open-source* yang dirancang untuk mengotomatisasi alur kerja akuntansi enterprise dan UMKM. Platform ini menggabungkan *Optical Character Recognition* (OCR) berbasis AI untuk ekstraksi faktur, pencocokan transaksi bank otomatis (*fuzzy matching*), serta penyusunan laporan keuangan *real-time*.

---

## ✨ Fitur Utama

* 🧾 **Pemrosesan Faktur Otomatis (AI OCR):** Ekstraksi data otomatis dari dokumen PDF, foto faktur, dan kuitansi dengan akurasi tinggi.
* 🏦 **Rekonsiliasi Bank Otomatis:** Pencocokan transaksi mutasi bank dengan buku kas menggunakan algoritma pencocokan cerdas.
* 📊 **Pelaporan Keuangan Real-Time:** Penjumlahan otomatis untuk Laporan Laba Rugi (*P&L*), Neraca (*Balance Sheet*), dan Laporan Arus Kas (*Cash Flow*).
* 🔄 **Integrasi API Perbankan & ERP:** Konektor siap pakai untuk sistem ERP populer (Odoo, SAP) dan Payment Gateway.
* 🇮🇩 **Kepatuhan Pajak Indonesia:** Perhitungan otomatis PPN, PPh 21/23, serta ekspor format e-Faktur.
* 🔒 **Jejak Audit Terenkripsi (*Immutable Audit Logs*):** Pencatatan riwayat transaksi yang aman untuk kebutuhan audit internal/eksternal.
